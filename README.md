# Interactive C Programming Learning Platform

## Overview
This project is an **interactive learning platform** for **Grade 9–10 students** to learn **C programming**. It provides beginner-friendly modules, hands-on examples, and practice exercises to help students understand programming logic and syntax.

Topics covered:
- Variables & Data Types
- Operators
- Conditional Statements
- Loops
- Arrays
- Basic Functions

---

## Features
- Step-by-step instructional examples
- Practice exercises and quizzes
- Self-paced learning
- GitHub repository with all code examples

---

How to Use
- This repository is currently a **planning framework**.  
- Code examples and exercises will be added in their respective module folders.
